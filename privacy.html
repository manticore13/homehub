Home Hub privacy policy

Last updated: November 8, 2026

Home Hub is a private Home Assistant installation used by a single household. Its only user is the owner.

What data is accessed

With the owner's consent, Home Hub reads Nest thermostat information (temperature, humidity, heating and cooling status) and can change thermostat settings through the Google Nest Smart Device Management API.

How data is used and stored

The data is used only to display and record home energy and climate information. It is stored on a computer inside the owner's home. It is not sold, shared with, or transferred to any third party, and it is not used for advertising.

Google user data

Home Hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Stored data can be deleted from the home server at any time.
